## Verbs the shell's own scripts and units depend on

Not all of them are public, but their callers ship in the same tree: a change must update the caller in the same commit (`api-check` fails, check `internal`, if one of them disappears). Descriptions in Spanish, as in the code.

| Verb | Class | Used by | Chain |
|---|---|---|---|
| `lockNow` | internal | `scripts/sumi-lock` | Lock: `loginctl lock-session` → hypridle `lock_cmd`/`before_sleep_cmd` → `scripts/sumi-lock [session\|instant]` → `lockNow <reason>`; si no bloquea, el helper lanza hyprlock. También el botón Lock en modo directo (F5d) |
| `lockStatus` | public | `scripts/sumi-lock` | Lock: `scripts/sumi-lock rescue` (unidad `sumi-lock-rescue.service`) lo lee para no lanzar hyprlock si la shell volvió y sostiene el bloqueo. Es también público (lectura) |
| `notifServer` | internal | `scripts/notif-server` | Notifications: `scripts/notif-server shell\|off` lo usa para guardar el ajuste del servidor antes de reiniciar la shell y escribir o borrar la activación D-Bus |
| `reload` | public | `systemd/sumi-shell.service` | Units: `ExecReload` de `systemd/sumi-shell.service`. Es también público |
| `status` | public | `scripts/notif-server` | Notifications: `scripts/notif-server` lee `.notifs` (enabled, running…) para saber si el cambio entró. Lo que lee fuera de los campos garantizados es interno: cambiarlo exige cambiar notif-server |
